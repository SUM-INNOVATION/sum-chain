WHY THIS AUDIT EXISTS
=====================
Merging the two release-blocker branches reported success twice while losing
work. `git apply --3way` on one conflicted test file discarded 267 lines and
still compiled, because the only symbol the loss broke was an import the
dropped code alone used. Separately, a cherry-pick that stopped at a conflict
left six of eight commits unapplied -- 77 symbols -- and the tree compiled,
because the missing code was additive and nothing referenced it.

A green compiler is not merge evidence. This audit enumerates every function,
public item, test, execution-boundary declaration, manifest row, activation
field and error variant in both parents and requires each to be present in the
union or classified above.
